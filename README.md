## Como Publicar no GitHub
1. Crie o repositório público com o nome exato `odilonmendes.github.io` em sua conta: [https://github.com/new](https://github.com/new).
2. Configure o remote do git:
   ```bash
   git remote set-url origin https://github.com/odilonmendes/odilonmendes.github.io.git
   git push -u origin master
   ```
   *(ou `main`, de acordo com sua preferência)*
3. No GitHub, acesse **Settings > Pages** e certifique-se de que o **Source** está configurado para **GitHub Actions** (ou Deploy from a branch).
4. O GitHub Actions fará o build e publicação automaticamente!
